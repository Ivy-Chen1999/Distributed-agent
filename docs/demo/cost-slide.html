One evolution cycle, if it were paid for

The cycle has not run against a real model yet, so this is a bound, not a measurement. A cycle is capped at 60 GEPA metric calls; on the fake backend 62 metric calls needed 14 graph runs, because repeated evaluations are cached. At $1.17 per Claude run that is about $16 (14 runs) to $70 (60 runs) of API-equivalent usage, plus val replays. The first real cycle's logged usage replaces this estimate.

Safeguards

Every api call now records its list-price cost (2026-10-15 fix), so --max-usd on cost sweeps and the evolve budget are enforced on api runs; a model without a known price is refused by any USD cap. Eval reports also record the judge's tokens and cost per case (judge_cost_usd), so the first formal run replaces the judge estimate above. The OpenAI account carries a monthly limit as the outer cap.
